手撕

2 道 coding

1. 字符串 DIFF 页面

（vibe coding）实现一个能够考虑空白字符、零宽字符、换行符等特殊字符的字符串 DIFF 交互页面，基本要求如下：​

  • 不依赖任何前端框架与工程脚手架，最终产物为内联了 CSS 与 JS 的 html 文件；​
  • 界面有两个输入框，第一个字符串代表原始字符串，第二个字符串代表变更后的字符串；​
  • 界面有一个 DIFF 点击按钮，点击以后展示字符串对比效果；​
  • 字符串对比界面交互与颜色参考 github，只需要考虑左右对比模式；​
  • 字符串 DIFF 需考虑空白字符、零宽字符、换行符等特殊字符的友好展示；​

2. 基于 Vue 的倒计时

做一个基于 vue 的倒计时组件，需要接受入参 time，单位为秒，代表要倒计时的秒数​，并转换成 时:分:秒 展示倒计时，每隔 1 秒更新倒计时。​设计三个控制按钮，一个 开始，一个 暂停，一个重置。（可能会存在计时不准确的问题，怎么解决）


  • 倒计时手写不出来的时候基本上已经结束了，还是又问了我几个关于 agent 的问题

问答题

    1. 学习前端的路径，学习 ai 的路径 略
    1. mcp 和 skill 的区别 渐进式披露 消耗 token 量 MCP 的两种调用方式
    1. 平常工作用什么 skill 比较多，有常用的吗
  • 3. 最近接触什么 agent 相关的新名词？Harness Engineering
