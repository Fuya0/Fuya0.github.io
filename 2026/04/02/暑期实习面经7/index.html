八股：

HTTP 是什么

HyperText Transfer Protocol 是一个应用层协议，用于在客户端和服务器之间传输数据
特性 说明
无状态 每次请求独立
基于请求-响应 Client → Request → Server → Response
文本协议（HTTP/1.1） 可读性强
可扩展 Header 可扩展

讲一讲浏览器输入 URL 并按下回车之后发生了什么

URL 解析 → DNS 解析 → TCP 连接 → HTTP 请求 → 服务器处理 → 返回响应 → 渲染

四次挥手可以由服务端发起嘛

可以，TCP 是全双工，任何一方都可以主动关闭连接，谁先调用 close()，谁先发 FIN

TCP 与 UDP 的对比
特性 TCP UDP
是否连接 有 无
是否可靠 是 否
是否有序 是 否
速度 慢 快
使用场景 HTTP、文件传输 视频、游戏、DNS

UDP 协议下，两端是怎么连接的

UDP 不建立连接，直接通过 IP 和端口发送数据
